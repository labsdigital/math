1. Apa itu Persamaan Kuadrat?

Persamaan kuadrat adalah polinomial berderajat dua. Bentuk umumnya adalah:

$$ax^2 + bx + c = 0$$

Memfaktorkan persamaan kuadrat berarti mengubah bentuk penjumlahan tersebut menjadi bentuk perkalian dua suku binomial:

$$x^2 + bx + c = (x + p)(x + q)$$

Syarat utamanya adalah: $p + q = b$ dan $p \times q = c$.

2. Berkenalan dengan Algebra Tiles (Ubin Aljabar)

Untuk memahami faktorisasi agar tidak hanya sekadar menghafal rumus, kita gunakan pendekatan visual berupa ubin.

x²
Ubin x² : Persegi biru besar. Mewakili luas daerah $x \times x$.
x
Ubin x : Persegi panjang hijau. Mewakili luas daerah $x \times 1$. Bisa diletakkan vertikal atau horizontal.
1
Ubin 1 : Persegi kuning kecil. Mewakili luas daerah satuan $1 \times 1$.

Ubin Negatif (Merah)

Jika persamaan memiliki nilai konstanta atau koefisien negatif, kita menggunakan ubin berwarna merah (berlaku untuk $-x^2$, $-x$, maupun $-1$). Ubin merah membatalkan ubin biasa jika digabungkan.

-x²
-x
-1
(Ubin merah digunakan untuk koefisien negatif).

3. Filosofi Pemfaktoran = Membangun Persegi Panjang

Rahasia utamanya adalah: Jika Anda diberikan persamaan $x^2 + 5x + 6$, kumpulkan ubin sebanyak itu (1 biru, 5 hijau, 6 kuning).

Tugas Anda adalah menyusun semua ubin tersebut agar membentuk sebuah Persegi Panjang Sempurna tanpa ada ruang kosong atau ubin berlebih.

Jika berhasil, panjang dan lebar dari susunan tersebut adalah faktornya! Mari coba di tab Visualisator.
